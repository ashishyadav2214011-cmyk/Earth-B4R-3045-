# EarthFall-B4R 3045 — Levels 0–10

A self-contained browser prototype of the first 11 levels.

## Levels
0. The Remaining Earth
1. Dead Zone
2. Green Pocket
3. Vagas Control Zone
4. No-Plant Region
5. Flooded Earth
6. Radiation Belt
7. Dead City
8. Orbit
9. Moon
10. Mars

## Included
- Realtime survival meters
- Movement
- Scan system
- Level objectives and progression
- Resource inventory
- Basic building action
- Local save/reset
- Keyboard controls: Arrow keys, E, Q
- Mobile-friendly UI
- `: Spaze AI :` in-game guide

## Run
Open `index.html` in a modern browser.

This is a prototype foundation, not a production Android APK or full 3D game.
